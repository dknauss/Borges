with `npm run sweep` for both corpora. Each figure counts citation details
(title, authors, year, container, DOI, ISBN, pages, publisher) a reader gets
right, of those the works have. "Printed" is what the style puts on the page

|---|---|---|---|
| Twelve works, APA 7 | 67 | 65 | 65 |

Every value the models missed was one the style left off the page (an ISBN,
the authors behind "and others", a last page, a DOI OSCOLA omits, a web
page's publisher), apart from one judgement call: the container of a GitHub
pull request.

## What Zotero saves

`npm run zotero-ts`, against the Zotero translation server built from its
`main` branch (commit 672d4f3). On the plain page and the Borges page with
its defaults, Zotero finds only the eight DOI links and looks each up at
Crossref or DataCite; the four books, the chapter, and the web page are not
saved. With COinS on, it saves all twelve from the page itself.

| Page | Works saved | Details correct (of 67) |
|---|---|---|
| Plain list | 8 | 43 |
| Borges, defaults | 8 | 43 |
| Borges, all layers | 12 | 66 |

One of three runs of the plain page saved six works and 32 details: a DOI
lookup timed out. Zotero saved the preprint and the web page as journal
articles, keeping their fields.

## Structured-data checks on a live page

On `https://m.arginalia.com/the-page-is-an-interface/` (84 works, Borges
1.16.0), the Schema.org validator found no errors or warnings. Google's Rich
Results Test read the bibliography's `ItemList` as a carousel and marked it
invalid ("two or more mutually-exclusive properties"): each `ListItem` had
both `url` and `item`. This branch drops the `url`. It also read 18 cited
works typed `ScholarlyArticle`, `Article`, or `BlogPosting` as Article rich
results, valid with optional fields missing.

## Gaps these runs found

- JSON-LD gave four encyclopedia entries no container. Fixed on this branch:
  they are now part of their reference work.
- COinS has nowhere to put a web page's or a piece of software's publisher,
  so Zotero's reader recovers 123 of the 36-work list's 130 details.
- In APA 7, an arXiv preprint prints its number as "arXiv:arXiv:1706.03762":
  the arXiv lookup stores the number with its prefix, and the bundled APA
  style adds the publisher again.
